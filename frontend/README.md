# JR AI Resume

A recruiter-facing AI resume chatbot UI built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Features
- Multi-page recruiter UI with Home, Experience, Projects, Skills, Chatbot, Resume, and Contact pages
- Mock AI chatbot experience with recruiter-focused sample responses
- Responsive layout for desktop, tablet, and mobile
- Reusable UI components and motion-based page transitions
- Tailwind CSS design system with navy, cyan, and soft gradients

## Setup

1. Open a terminal in the `frontend` folder:

```bash
cd frontend
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open the provided local URL in your browser.

## Build

```bash
npm run build
```

## Notes
- This frontend is intentionally static and uses local mock data for the chatbot flow.
- No backend or external API is required to run the interface.
